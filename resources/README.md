## Model limitations

The simulators are teaching tools, not forecasts. Results depend on simplified parameters and relationships. A genuine data flywheel requires relevant, lawfully usable data that improve a metric capable of creating value. More users or more data do not guarantee better quality.

## Use and contribution

- Access HTML files through GitHub Pages; neither `htmlpreview` nor RawGitHack is required.
- Cite the resource date and underlying source when reusing a statistic.
- Document assumptions when contributing a model.
- Read [CONTRIBUTING.md](../CONTRIBUTING.md) before submitting material.
